# HW1 - NOT Gate (VHDL + Logisim-evolution)

디지털논리회로설계 과제: NOT 게이트를 VHDL로 작성하고 Logisim-evolution에서 시뮬레이션합니다.

| 파일 | 설명 |
|---|---|
| `not_gate.vhd` | NOT 게이트 VHDL 코드 (`y <= not a`) |
| `not_gate.circ` | Logisim-evolution 프로젝트 (VHDL 엔티티 + 입력 a, 출력 y) |
| `not_gate_tb.vhd` | Questa 확인용 테스트벤치 |
| `report.pdf` | 보고서 (코드, 회로, 시뮬레이션 결과, 설명) |
| `screenshots/` | Logisim 시뮬레이션 스크린샷 |

## 결과

| a | y |
|---|---|
| 0 | 1 |
| 1 | 0 |
